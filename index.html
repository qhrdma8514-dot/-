ABOUT HR SOUND

프로페셔널 오디오 보정 및 사운드 엔지니어링 프로세스를 적용하여 완성도 높은 음원을 제작합니다.

1:1 디테일 피드백 반영 및 레퍼런스 맞춤형 톤매칭/믹싱

문의 양식

아래 안내사항을 읽으신 뒤 내용 작성 및 녹음 파일과 함께 문의 바랍니다.

1. 곡 제목 / 원곡 링크
(작업 곡 제목 및 원곡 유튜브/링크 기입)

2. 업로드 예정 플랫폼 주소
(YouTube, SoundCloud 등 게시 플랫폼 주소)

3. 보컬 에디팅 및 인공화음 여부
- 기본적으로 원곡 기반 기계음이 느껴지지 않는 선에서 타이트하게 보정합니다.
- 부른 느낌을 살린 자연스러운 연출 희망 시 별도 세부사항 기재 (미필요시 'X').
- 인공화음 추가 필요 여부 기입.

4. 작업 방향 및 요청 사항 (선택 Type 기재)
원하시는 사운드 톤앤매너, 레퍼런스, 분위기('묵직하게', '시원하게' 등) 작성.
(별도 요청이 없을 시 엔지니어의 해석과 스타일에 따라 진행됩니다)

5. 빠른마감 여부
(빠른마감 필요 시 기입)

PRICE & TYPE

작업 난이도 및 보컬 에디팅 디테일에 따른 세부 Type 구분입니다.

Premium Premium Type

Premium Type 세부 작업 공정
Edit: Pro Tools 기반 정밀 파형튠(박자) → Melodyne Studio → Auto Tune Graph Mode & Repitch → Pro Tools Pencil Tool & iZotope RX 11 / Acon Digital (립노이즈 및 잡음 수작업 일대일 제거) → Inst & Vocal Rough Mix
Mix: Vocal Automation (곡의 기승전결에 따른 세밀한 보컬 수작업 제어로 타격감과 감정선 극대화) → 레퍼런스 맞춤 톤매칭 → 전체 밸런스 조정 → Mix Bus 작업
Master: 단순히 볼륨을 높이는 것에 그치지 않고 전체적인 입체감과 완성도를 끌어올리는 정밀 마스터링

Standard Standard Type (기본 단독)

Standard Type 세부 작업 공정
Edit: Melodyne Studio (음정 & 박자) → Auto Tune Graph Mode & Repitch → iZotope RX 11 / Acon Digital (잡음 일괄 제거) → Inst & Vocal Rough Mix
Mix: 레퍼런스 및 보컬에 맞춘 이상적인 톤매칭 → 전체 밸런스 조정 → Mix Bus 작업
Master: 레퍼런스 기준 완성도 높은 밸런스 마스터링

Lite Lite Type

Lite Type 세부 작업 공정
Lite Type은 박자 수정을 최소화하고 음정 보정 위주로 진행됩니다. HR Sound 독자 프리셋을 적용하여 가볍게 작업하시거나 연출감을 테스트하기에 적합합니다.
Edit: Melodyne Studio → iZotope RX 11 / Acon Digital (잡음 일괄 제거) → Inst & Vocal Rough Mix
Mix/Master: 독자 프리셋 적용 → 밸런스 조정 → 러프 마스터링

NOTICE

  • 수정 횟수: 기본 3회 무료 제공 (이후 추가금 발생). 피드백 전달 시 한 번에 정리해서 전달 부탁드립니다. (작업자 과실 수정은 횟수 차감 제외)
  • 작업 기한: 솔로 및 듀엣 기준 1차 결과물 전달까지 5일 ~ 최대 2주 소요됩니다.
  • 기본 트랙 수: MR 제외 메인 보컬 포함 최대 5트랙 기준입니다. (LR 분할, 숨소리 분할 트랙은 1트랙으로 산정)
  • 기본 적용 Type: 별도 지정이 없으실 경우 Standard 타입으로 진행됩니다.
